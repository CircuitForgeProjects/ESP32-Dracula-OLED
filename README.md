# 🧛‍♂️ Dracula Song OLED Project

An ESP32-based project that displays Dracula song lyrics on an OLED display with custom animations and visual effects.

## Components
- ESP32 DOIT DEVKIT V1
- SSD1306 128×64 OLED
- Jumper wires

## Connections

| OLED | ESP32 |
|---|---|
| VCC | 3.3V |
| GND | GND |
| SDA | GPIO 21 |
| SCL | GPIO 22 |

OLED I²C Address: `0x3C`

## Libraries
- Adafruit GFX Library
- Adafruit SSD1306

## Features
- Dracula song lyrics
- OLED animations
- Visual effects
- ESP32 + I²C communication

## How to Run
1. Connect the OLED to the ESP32.
2. Install the required libraries.
3. Open the `.ino` file in Arduino IDE.
4. Select ESP32 DOIT DEVKIT V1.
5. Upload the code.
